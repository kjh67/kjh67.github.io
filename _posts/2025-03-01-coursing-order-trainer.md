As part of a current quest to improve my Conducting skills (that is, conducting in the 'keeping it right' sense, rather than the 'calling it right' sense), I found myself wanting to practise transposing coursing orders outside the tower. Since, as of February 2025, I could find not find any existing resources to do this, I created my own [coursing order trainer](coursing_order_trainer). Current features include:
- Randomly generating the next call with which to permute the coursing order.
- Checking whether the user transposed the coursing order correctly.
- Forcing the user to practice remember the coursing order (as they would need to in the tower) by hiding the current coursing order (this can be unhidden at any time).
- Simulating another bell going wrong and needing correction: the probability of this happening can be adjusted in the settings.

My hope is that other aspiring conductors might find this tool helpful. Currently only standard calls for Major methods are included, but support for other stages and more calls is on the table for sometime in the future...
